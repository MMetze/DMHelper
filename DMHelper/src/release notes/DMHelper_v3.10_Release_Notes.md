# DMHelper v3.10 Release Notes

---

## Reddit Post (r/dmhelper, r/VTT, r/DnD etc.)

---

**DMHelper v3.10 is here — and this update is all about smoother play, smarter combat, and fixing the rough edges that matter most at the table.**

---

Hey everyone! 🎲

We’ve just shipped **DMHelper v3.10**, a focused update built around better performance, cleaner combat flow, and a few quality-of-life improvements that make the app feel much more polished during actual play.

The biggest headline is this:

### 🚀 Video playback is much smoother (and works again on macOS)

We fixed the major performance issues in video playback and made the Mac experience far more reliable, including direct support for Apple Silicon. If you’ve been waiting for smoother map video playback, this is the update for you.

But that’s not all — we also tightened up some combat and initiative workflows:

- movement speed categories are now respected for combatants with multiple movement types
- combatant group creation is more consistent and stable
- drag-and-drop group management is now supported
- initiative and token actions feel cleaner and more predictable

Now, onto the full changelog:

---

### ✨ New Features

- **Major video playback performance improvements** — smoother playback and a significantly better experience
- **Direct Apple Silicon support** — no extra workaround needed on modern Macs
- **Movement speed category handling** — movement types like flying, walking, and burrowing are now respected correctly for multi-speed combatants
- **Improved combatant grouping workflow** — fixes and polish for group creation and management
- **Drag-and-drop group updates** — add or remove combatants from groups more naturally
- **Contextual “Edit Conditions” action** — right-click access for combatants in initiative order or tokens on the battle map, including multi-selection support

---

### 🐧🍎 Platform News

- **Apple Silicon support** — direct support is now included for M-series Macs

---

### 🔧 Fixes & Improvements

- Fixed a variety of issues with combatant group creation
- Added drag-and-drop support for adding/removing combatants from groups
- Added right-click “Edit Conditions” for combatants in initiative order or tokens on a battle map, including multi-selection
- Health bars can now be set to Off, DM Only, or DM & Player
- Health bars no longer rotate with tokens
- Damaging/healing characters now updates correctly in the initiative list
- Improved event add/remove behavior
- Improved default Lair Actions behavior

## GitHub Release — v3.10.0

**Tag:** `v3.10.0`  
**Title:** DMHelper v3.10 — Video Playback Fixes, Apple Silicon Support & Combat System Improvements

---

### Overview

v3.10 is a focused quality and stability release centered on smoother macOS video playback, direct Apple Silicon support, and a number of important combat and initiative workflow improvements. The update also resolves several issues in group management, token behavior, and event handling.

---

### Performance

- **Video playback improvements** — major fixes to playback performance and compatibility on macOS
- **Apple Silicon support** — direct support for M-series Macs without extra configuration

---

### New Features

| Feature | Description |
|---|---|
| Video Playback Improvements | Improved playback smoothness and stability, especially on macOS |
| Apple Silicon Support | Native support for Apple Silicon devices |
| Multi-speed Movement Handling | Respects speed categories for combatants with multiple movement modes |
| Combatant Group Improvements | Better logic and polish for group creation and management |
| Drag-and-Drop Group Management | Add or remove combatants from groups with drag-and-drop |
| Right-click Condition Editing | Edit conditions from initiative entries or map tokens with multi-select support |

---

### Platform Support

- **macOS** — improved playback and stability, including Apple Silicon support
- **Windows** — continued support with no disruption to existing workflows
- **Linux** — ongoing compatibility support for the desktop experience

---

### Bug Fixes & Minor Improvements

- Fixed multiple issues with combatant group creation
- Added drag-and-drop support for group membership changes
- Added right-click “Edit Conditions” support for combatants and tokens, including multi-selection
- Health bars can be set to Off, DM Only, or DM & Player
- Health bars no longer rotate with tokens
- Damaging/healing characters now updates correctly in the initiative list
- Improved event add/remove behavior
- Improved default Lair Action behavior
